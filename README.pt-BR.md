# Violet Recomp

Port experimental de Pokémon Violet por recompilação estática, baseado em [ZA Recomp](https://github.com/Hexveil404/PokeZ-ARecomp) e [LAS Recomp](https://github.com/peiikai/LASRecomp).

**O port está em desenvolvimento. Uma versão jogável de Violet ainda não foi verificada.** A importação dos pacotes e a geração de código foram verificadas; isso não confirma a compatibilidade em jogo.

Não é necessário extrair o jogo manualmente. O importador lê seus próprios arquivos XCI/NSP e suas chaves do Switch. Nenhum arquivo do jogo, chave ou código gerado é distribuído.

Consulte o [README em inglês](README.md) para o estado atual, os requisitos e os comandos de preparação. Os perfis configurados são 1.0.0 e 4.0.0. Os downloads, imagens e recursos de Z-A não representam uma versão funcional de Violet.
